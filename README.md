# Biblioteca dos Nerds 🎮
Site estático pronto para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Vá em **Settings → Pages**.
4. Escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
5. Salve.
